# Copies of FabriChat for the compiled pattern language

The 16 modules of the program of `patterns/system/fabrichat/room.tsx` and
`patterns/system/fabrichat/manager.tsx`, each in the directory it has under
`patterns/system/`. They are copies: the patterns that today's runtime runs stay
as they are. Each change to a copy is a commit of its own that names the detail
of the language it stands in for, and notes 720 on of `../../SPEC-NOTES.md` list
them.

`../home/` holds the other 10 modules of the program of
`patterns/system/home/home.tsx`, which import these.
